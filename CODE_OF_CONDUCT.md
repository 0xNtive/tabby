# Code of Conduct

tabby follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else in the project.

Report problems privately to the maintainer through [GitHub](https://github.com/0xNtive). Reports are handled confidentially.
