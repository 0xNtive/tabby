# Theme contrast audit

Generated by `npm run export` from `lib/themes.js`. Ratios are WCAG 2.x contrast.

- **Text** — theme foreground on its background. Every theme is AA (4.5:1) or better; tests enforce it.
- **Tinted text** — worst case over every session color at the *bold* tint. Tints keep OKLCH lightness,
  and tabby shrinks a tint rather than let text read worse than the theme itself.
- **Accents** — raw palette accent vs background. Accents below 3:1 are pale colors in light themes;
  tabby darkens them automatically wherever they carry information (the cursor, ≥ 3:1) and lightens
  island dots to ≥ 4:1 on black. Title markers are emoji and unaffected.
- **Very high** (> 15:1) is flagged because maximum contrast can itself cause glare for some people.
