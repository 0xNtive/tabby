# tabby website

The public landing site for tabby, deployed at **https://claude-tabby.vercel.app**.
Plain static files with no framework and no build step.

```
site/
├── index.html          landing page
├── terms.html          TERMS.md rendered as a page (generated, see below)
├── 404.html            lost-cat page (Vercel serves it for unknown paths)
├── themes.json         theme data for the gallery (generated by `npm run export`, don't hand-edit)
├── favicon.ico
├── assets/
│   ├── site.css        all styles
│   ├── site.js         demo terminal, island, theme gallery, copy buttons
│   ├── logo.svg · app-icon-1024.png   (from ../brand)
│   ├── favicon.svg · favicon-32.png · apple-touch-icon.png
│   └── og.svg → og.png social card (1200×630)
└── tools/
    ├── terms-to-html.py       TERMS.md → terms.html
    └── terms.template.html    page shell for the terms
```

## Run locally

```sh
cd site
python3 -m http.server 4173
# open http://localhost:4173
```

`themes.json` is fetched at runtime, so open the site over HTTP, not `file://`.
The local server doesn't apply `vercel.json`, so `/terms` needs `/terms.html` locally.

## Deploy

The Vercel project `claude-tabby` is linked at the **repo root**. The root `vercel.json` serves this folder
(`"outputDirectory": "site"`) with clean URLs, long-cached `/assets/*` and security headers, and the root
`.vercelignore` keeps `site/tools/` and this README out of the deploy.

- Pushing to `main` deploys automatically (Vercel Git integration).
- Manual deploy: `vercel deploy --prod` from the repo root.

## Editing notes

- **Cache busting.** `/assets/*` is served with `Cache-Control: immutable` for a year. After you change
  `site.css` or `site.js`, bump the `?v=` query in `index.html`, `terms.html`, `404.html` and
  `tools/terms.template.html` (for example `?v=2` → `?v=3`). Otherwise returning visitors keep the old file.
  Changed images need a new filename or a new query string for the same reason.
- **Terms.** After editing `../TERMS.md`, run `python3 site/tools/terms-to-html.py` from the repo root.
  The script keeps the text identical and only adds markup.
- **Themes.** The gallery, the chip counts and the "57 themes" heading all come from `themes.json`.
  Regenerate it with `npm run export` from the repo root.
- **Social card.** `assets/og.svg` is the source for `assets/og.png`. Re-render it at 1200×630 with headless Chrome
  (fonts load from Google Fonts), for example:

  ```sh
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
    --user-data-dir="$(mktemp -d)" --window-size=1200,630 --virtual-time-budget=8000 \
    --screenshot=og.png "file://$PWD/site/assets/og.svg"
  ```

  Then check the size with `sips -g pixelWidth -g pixelHeight og.png`. Headless Chrome sometimes stays running
  after writing the file; quit it once the PNG exists.
- **Motion.** Looping animations run only without `prefers-reduced-motion`, and they pause while offscreen.
  The island uses a small spring solver in `site.js` (response and damping, as in Apple's APIs).
- **Keyboard.** The island shortcuts work on the page: ⌃⌥Space opens the island, ⌃⌥N jumps to the session
  that needs you, ⌃⌥1–4 switch sessions, ⌃⌥G tiles windows and ⌃⌥M changes the island mode.
