Local, quiet and cheap to run

tabby is a few hooks and a small app on your own machine. Here is everything it does beyond that.

No servers, no telemetry.
tabby collects nothing. Your prompts, code and file names stay on your machine.
One network call.
To name a tab, tabby sends a few recent prompts to Claude Haiku through your own Claude Code login. tabby config namer heuristic names tabs locally instead.
Out of Claude's way.
Hooks run async, so Claude never waits on tabby. The tool-use fast path takes about 10 ms.
Easy to remove.
tabby uninstall reverts everything, and settings.json is backed up before tabby changes it.

Questions

Something else? Open an issue on GitHub.

Does it use tokens?

/tab commands never do; a hook answers them. Naming a tab uses about 500 Haiku tokens per rename, through your own Claude login. That's roughly $0.001, and Pro and Max plans cover it.

Will it slow Claude down?

No. tabby's hooks run async, so Claude never waits for them. The tool-use fast path takes about 10 ms.

Does it work with iTerm2, tmux or VS Code?

Yes. iTerm2 gets native tab colors, and tmux gets the window name and a status-bar color. VS Code and Cursor get the title and colors; set "terminal.integrated.tabs.title" to "${sequence}" to see the name in the tab. tabby doctor shows what works in your terminal.

Can I pick my own colors?

Yes. /tab color teal picks one of eight colors, /tab color #7fc489 takes any hex, and /tab theme nord all applies one of 57 themes to every tab.

Is it affiliated with Anthropic?

No. tabby is an independent project. Claude and Claude Code are trademarks of Anthropic.

Is it free?

Yes. Future versions may show clearly labeled sponsored messages in tabby's own interface, such as the island or the CLI. Never in your Claude conversations. The Terms have the details.

How do I remove it?

Run tabby uninstall, or /plugin uninstall tabby@tabby inside Claude Code. tabby uninstall also reverts every change tabby made to your settings.
