macOS · Tabby Island

All your sessions, one glance up.

Tabby Island sits at the top of your screen, under the notch. Collapsed, it is one dot per session. It speaks up when a session finishes or needs you.

One line per session: dot, name, status, context. ⌃⌥M switches.

Status chips, how far along a working session is, and the context it has used.

Everything, always: summary, current task, your last prompt, tokens and cost.

Open it with a hover, or ⌃⌥Space.

Every session's name and status, how far along it is, and how much context it has used. A working session shows "2 of 5 tasks · ~3m left" from Claude's task list, or "~2m left · usually 6m" from how long its turns take. Click a row to jump to its tab.

open the island from the keyboard
⌃⌥N
jump to the session that needs you
⌃⌥1–9
jump to a session
⌃⌥L
start a session in a recent folder
⌃⌥G
tile your windows

switch the detail level

  • Rest on a session for the full picture.

    What it needs and what to do about it, its summary, your last prompt, tokens, cost, folder and terminal. Open Tab jumps there.

  • End a session, with a safety catch.

    It asks first. The conversation stays in history, so claude --resume brings it back.

  • Rename, recolor, re-theme in place.

    Right-click a row, or press R, C or T with the keyboard open.

  • Keyboard first.

    ⌃⌥Space, then arrows and ↩. Every global shortcut can be changed.

  • Updates in one click.

    When a new version is out, the island shows a button. Or /tab update in Claude. It updates the plugin and the island together.

  • Under 1% CPU, always.

    SwiftUI for layout, Core Animation for anything that loops. Tabby Island idles like a menu-bar clock.

    No servers, no telemetry, no accounts, and no network code in the app.

Focus mode

Five windows, one voice.

With several sessions running, their scrolling output competes for your eyes. Turn on Focus mode, and while Claude works, every Terminal window you're not in shows only its topic and what's running: one line per agent, with a spinner and how long it has been at it. The window opens again the moment Claude needs you or it's your turn. Prefer it calmer still? Tick one box, and a finished window stays covered, with a Your turn button to click.

Full-screen windows come back, every session gets its own cell, and a portrait screen stacks them in rows. Tile them all, only the active ones, or the ones you choose. ⌃⌥N jumps to the one that needs you.

  • Keep your main screen free.

    Choose which screens get sessions: the one you're on, all of them, or the ones you pick. Tick only your vertical monitor, and your main screen stays yours.

    Active ones, all of them, or checkboxes. tabby tile --active does the same from a terminal.

  • A new session in two keystrokes.

    ⌃⌥L lists your recent and most-used folders. Type to filter, name it if you like, press ↩. It opens on the screen you chose.

/tab

One line of control.

/tab is answered by a hook, so it's instant and never costs tokens. The same words work as tabby in a terminal, and as flags when you launch Claude.

Questions, answered.

        

          
Does it cost anything?
No. tabby is free and MIT licensed. Tab names come from Claude Haiku through your own Claude Code login, about 500 tokens each, which Pro and Max cover.

          
What leaves my machine?
One thing you typed: to name a tab, tabby sends that session's last few prompts (trimmed), a short excerpt of Claude's last reply and the project folder's name to Claude Haiku, through your own Claude Code login and the provider it already uses. Type /tab namer heuristic and names are worked out on your machine instead. Besides that, tabby asks github.com for a newer release every few hours and downloads Tabby Island from GitHub's releases; neither sends anything about you, and the check can be turned off. No servers, no telemetry, no accounts. Tabby Island has no network code at all, and tabby's files in ~/.claude/tabby are readable only by you.

          
Is it safe to install?
tabby is open source with no dependencies, so everything it runs is in the repository. The installer shows the terms first, backs up your Claude settings before changing them, and tabby uninstall reverts every change. The naming call runs with no tools, no hooks and no plugins, so it can only return a name. Tabby Island asks for Accessibility and Automation only to arrange windows, find each session's window and jump to tabs; it never reads your screen or what you type. It is in beta and not yet notarized by Apple; the release zip carries a checksum and a build attestation you can verify.

          
How do I update?
When a new version is out, the island shows an Update button. Or type /tab update in Claude, or run tabby update in a terminal. It updates the plugin and the island together.

          
Which terminals work?
Terminal.app and iTerm2 get everything, including the island, Focus mode and tiling. Ghostty, WezTerm, kitty, Alacritty, VS Code and tmux get names, colors and live status.

          
Why does tiling ask for Accessibility?
Moving a tab into its own window and bringing a full-screen window back use macOS window controls. tabby asks once, for Tabby Island, and never records your screen.

          
Something isn't working?
Ask Claude to “fix tabby”: it runs tabby doctor, which checks every part of the install, and fixes what it finds. Running the installer again is safe too.

          
How do I turn it off?
Type /tab off for one tab, or run tabby uninstall to revert every change. Your Claude settings file is backed up first.

          
Is this made by Anthropic?
No. tabby is an independent open source project. Claude is a trademark of Anthropic.
