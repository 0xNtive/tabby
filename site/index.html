Install in one line.

Needs Claude Code and Node 18. Setup shows the terms first, and tabby uninstall undoes everything it changes.

>curl -fsSL https://github.com/0xNtive/tabby/raw/main/install.sh | bash

Or inside Claude Code

/plugin marketplace add 0xNtive/tabby
/plugin install tabby@tabby
/tabby:setup

On a Mac the installer also builds Tabby Island and asks macOS for Accessibility, which lets tiling split tabs and bring full-screen windows back.

Free. Local. MIT.

Questions, answered.

Does it cost anything?

No. tabby is free and MIT licensed. Tab names come from Claude Haiku through your own Claude Code login, about 500 tokens each, which Pro and Max cover.

What leaves my machine?

Only the naming request, sent through your own Claude login. No servers, no telemetry, no accounts. Everything else lives in ~/.claude/tabby.

Which terminals work?

Terminal.app and iTerm2 get everything, including the island and tiling. Ghostty, WezTerm, kitty, Alacritty, VS Code and tmux get names, colors and live status.

Why does tiling ask for Accessibility?

Moving a tab into its own window and bringing a full-screen window back use macOS window controls. tabby asks once, for Tabby Island, and never records your screen.

How do I turn it off?

Type /tab off for one tab, or run tabby uninstall to revert every change. Your Claude settings file is backed up first.

Is this made by Anthropic?

No. tabby is an independent open source project. Claude is a trademark of Anthropic.
